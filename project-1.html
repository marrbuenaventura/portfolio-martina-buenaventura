Sport & Sweet — Kiosco Autoservicio

API REST y aplicación web de autoservicio para un kiosco de artículos deportivos. Backend en Node.js, Express y MySQL con arquitectura MVC; frontend en HTML, CSS y JavaScript vanilla. Proyecto integrador grupal de Programación III (UTN Avellaneda).
Self-service kiosk REST API and web app for sporting goods. Node.js/Express/MySQL backend (MVC architecture) and a vanilla JS frontend. Group integrator project for UTN's Programación III course.

Project Overview / Descripción del Proyecto

Sport & Sweet es una aplicación de autoservicio (kiosco) para una tienda de artículos deportivos, desarrollada en equipo como proyecto integrador de la materia Programación III. El sistema permite a los clientes navegar productos, armar un carrito y generar un ticket de compra, mientras que el backend gestiona productos y ventas mediante una API REST propia.

El backend está construido con Node.js, Express y MySQL, organizado siguiendo el patrón MVC (controllers, models, routes, middlewares), con ES Modules, un pool de conexiones vía MySQL2, manejo de sesiones con express-session y variables de entorno con dotenv. El frontend está hecho en HTML, CSS y JavaScript vanilla, con lógica de carrito basada en sessionStorage y una página de ticket/comprobante de compra.

Sport & Sweet is a self-service kiosk app for a sporting goods store, built as a group integrator project for the Programación III course. It lets customers browse products, build a cart, and generate a purchase ticket, while the backend manages products and sales through a custom REST API.

The backend is built with Node.js, Express, and MySQL, organized using the MVC pattern (controllers, models, routes, middlewares), with ES Modules, a connection pool via MySQL2, session handling with express-session, and environment configuration through dotenv. The frontend is built with vanilla HTML, CSS, and JavaScript, using sessionStorage for cart logic and a dedicated receipt/ticket page.
