Project Overview / Descripción del Proyecto

Este proyecto consistió en el diseño y desarrollo de una API REST completa para Sport & Sweet, un sistema de e-commerce de indumentaria deportiva, trabajado en equipo con una compañera de la Tecnicatura.

El backend está construido con Node.js, Express y MySQL, siguiendo el patrón MVC (modelos, controladores y rutas separados), con connection pooling para el manejo eficiente de conexiones a la base de datos. La autenticación se maneja con bcrypt para el hasheo de contraseñas y express-session para el manejo de sesiones, y el sistema incluye CORS configurado para la comunicación entre frontend y backend.

El proyecto cuenta con dos frontends conectados a la misma API: un cliente en JavaScript vanilla con catálogo de productos por categorías (zapatillas y ropa) y un carrito de compras lateral persistido en localStorage, y un panel de administración desarrollado con EJS que incluye login protegido y gestión de productos con soft delete (papelera).

This project involved designing and developing a complete REST API for Sport & Sweet, a sportswear e-commerce system, built as a team project with a classmate from the Tecnicatura.

The backend is built with Node.js, Express and MySQL, following the MVC pattern (separated models, controllers and routes), with connection pooling for efficient database connection handling. Authentication is handled with bcrypt for password hashing and express-session for session management, and the system includes CORS configured for frontend-backend communication.

The project features two frontends connected to the same API: a vanilla JavaScript client with a category-based product catalog (sneakers and clothing) and a side cart persisted in localStorage, and an admin panel built with EJS including protected login and product management with soft delete (trash).
